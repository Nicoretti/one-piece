# Advanced

## Debug Options

* `-d`, `-d2`, `-d3`, `-d4`
* `-v`, `-x`, `-r`

::: notes
* -v writes transfered data also to stderr
* -x like v but data as hex
* -r dumps transfered data into file
* and more e.g. -lf see help/man page
:::
